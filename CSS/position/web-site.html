Componente 1 - Flexbox no Cabeçalho

Colocando o logo na esquerda e o menu na direita

Analogia da prateleira organizada: Quando colocamos display: flex; na barra do topo, todos os filhos entram na mesma linha. Depois, o comando justify-content: space-between; empurra o primeiro item (logo) para a ponta esquerda e o último item (links) para a ponta direita

.navbar { display:flex; justify-content: space-between; align-items: center; }

Componente 2 - Animações (@Keyframes)

Como a orca flutua sozinha e estilizaçãp do botão

Com o @keyframes flutuar, criamos um roteiro dizendo para a Orca subir -14px na metade do tempo (50%) e voltar ao normal em loop infinito (infinite). Já no botão, usamos padding para o texto respirar lá dentro e :hover + transition: 0.3s para ele crescer suavemente quando o mouse encosta!

@keyframes flutuar { 0%, 100% { transform: translateY(0px); } /* Posição inicial e final */ 50% { transform: translateY(-14px); } /* Sobe 14 pixels no meio da animação */ } .btn-mergulhar { padding: 14px 28px; /* "Plástico-bolha" interno que dá corpo ao botão */ border-radius: 8px; /* Arredonda as quinas do botão */ transition: 0.3s; /* Deixa a animação do mouse super suave */ } .btn-mergulhar:hover { transform: scale(1.08); /* Aumenta 8% quando o mouse passa por cima */ }

Na escuridão do oceano, a orca enxerga com o som! Ela emite cliques que viajam pela água, batem nos peixes e voltam como um eco, revelando o tamanho e a distância exata da presa.

Componente 3 - Box Model

Olhe atentamente para a caixa acima: Repare que o dotted (pontilhado) está na border (a moldura azul), enquanto o padding é só o espaço vazio (plástico-bolha) que impede o texto de encostar nas bolinhas! Já a margin é o espaço vazio do lado de fora para afastar esta caixa das outras.

.caixa-sonar { padding: 20px; /* 1. Espaço VAZIO por dentro (só aceita medidas!) */ border: 4px dotted #00d2ff; /* 2. A MOLDURA física (é AQUI que vai o dotted!) */ margin: 20px 0; /* 3. Espaço VAZIO por fora para afastar os vizinhos */ }
